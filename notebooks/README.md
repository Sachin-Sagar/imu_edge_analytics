## 1. Suite Architecture Overview

This suite of interactive Jupyter Notebooks provides an end-to-end signal processing, kinematics estimation, and edge power optimization engine for high-frequency 6-axis IMU telemetry recorded from a two-wheeled vehicle (motocross motorcycle) powered by a single-cylinder 2-stroke engine.

The suite is divided into two primary sections:
1. **Core Motion Analytics Suite** (`01` through `04`): Baseline telemetry ingestion, data hygiene, ballistic free-fall jump detection, 2-stroke vibration spectral analysis, Butterworth low-pass filter synthesis, and edge downsampling limits.
2. **Advanced Research & Kinematics Suite** (`Filter_and_PSD_extended`, `EDA_and_Downsampling_extended`): Deep mathematical investigations into parametric system identification (ARX), state-space discrete Kalman filtering, 3D vibration polarization (56.7° cylinder tilt), MEMS transducer mechanics, and IoT battery lifetime modeling.

All notebooks run natively against the first-principles synthetic dataset generated by [`../src/generate_synthetic_telemetry.py`](../src/generate_synthetic_telemetry.py) and stored at [`../data/motocross_imu_telemetry.csv`](../data/motocross_imu_telemetry.csv).
